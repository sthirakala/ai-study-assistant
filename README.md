# StudyBuddy | AI Study Assistant

## Live Demo

https://ai-study-assistant-hltk.vercel.app/

An AI-based study assistant built with React that allows users to upload their study material via PDF. Users can questions about their material and test their knowledge by generating quizzes and flashcards.

## Features

- Upload PDF Study Material
- Multiple Choice Quiz Generation
- Flashcard Generation with Front questions and Back answers

## Technology

- React
- React Router
- JavaScript
- Python
- Vite
- CSS3
- FastAPI
- LangChain
- Hugging Face
- FAISS
- GROQ
